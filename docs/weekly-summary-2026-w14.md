# 本周功能总结 (2026-03-27 ~ 2026-04-02)

- 新增 Turn Director 统一意图分类器，将意图从内容类型（confirm/decline/substantive）改为动作类型（advance/stay/need_help/redirect/exit），合并分类器与规划器为单次 LLM 调用，减少延迟
- 新增 Story Scaffold 机制，在游戏定义文件中配置故事收集策略，让每轮收集问题围绕故事主线而非重复固定模板
- 区分 naming_story 与 comparison_chart 两种合成类型：命名游戏采用双轮交互（描述→命名），观察游戏采用单轮交互（描述→推进）
- 新增儿童优先的故事合成流程：先邀请儿童自己编故事，拒绝则提供主题选择，最后由 AI 生成完整故事
- 新增 Cat1 游戏角色动画系统，支持场景视频片段的双视频交叉淡入淡出切换
- 修复场景视频切换时 canplay 事件丢失的问题，改为 listener 先于 load 绑定并增加 loadeddata 和超时兜底
- 修复视频模式下 frameKey 变化导致 CharacterDisplay 重新挂载、庆祝动画闪断的问题，改用稳定 key
- 新增场景动画状态指示器，在设备面板底部实时显示当前动画状态和场景名称
- 庆祝与结束步骤拆分为独立回合，徽章在整个庆祝和结束对话期间持续显示，并叠加 IB 概念标签
- 新增实时调试面板，显示 Turn Director 的动作、推理、响应方向、故事元素和 Speaker 错误信息
- 新增沉浸式角色音效和环境音效系统
- 新增流式 OGG/Opus TTS，替代整段生成的 WAV 格式，降低首字节延迟
- 新增创意多样性框架，通过变化提示和示例采样避免重复对话
- 用故事循环替代固定合成类型，统一所有 Cat5 游戏的故事生成流程
- 新增自动化评估系统：包含儿童模拟器、LLM 评委、评分标准模型和会话运行器 CLI
- 修复 Cat5 收集阶段不同步、提示质量和轮次随机化等多个问题
- Speaker 提示模板改为动态约束注入，避免二选一示例文本误导 LLM 生成不相关的选择题
- 推进动作时 Speaker 在当前步骤生成对话后再切换状态，防止下一步骤的指令污染当前回应
- 观察类游戏（如 polka_dot_patrol）在设备面板中显示物品默认标签名，替代空白名称
