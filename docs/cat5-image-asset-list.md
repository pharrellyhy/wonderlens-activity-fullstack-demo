## Image Specs

- **Format:** PNG with natural background (not transparent)
- **Recommended dimensions:** 1024x1024px (DALL-E default), displayed at ~144x144 in the UI
- **Style consistency:** All images in each game should feel like they belong together — same lighting mood, same level of detail, same color temperature
- **Child-friendly:** Target age 2-8. Items should be clearly recognizable at small sizes, not abstract

## DALL-E Prompt Templates

### Photo-Realistic Style
```
A close-up photograph of [ITEM DESCRIPTION], found outdoors in a garden/park/forest.
Natural warm lighting, shallow depth of field with soft blurred green background.
Child's-eye perspective looking down. Shot on iPhone, candid nature photography style.
Square format, 1024x1024.
```

### Illustrated/Storybook Style
```
A warm children's book illustration of [ITEM DESCRIPTION].
Soft watercolor-meets-digital style with gentle outlines and warm earth tones.
Natural outdoor setting with soft blurred background.
Friendly and inviting, designed for ages 3-7. Square format, 1024x1024.
```

Generate both styles for each item, then pick the best per image.

## Per-Round Item Mapping

Items are randomly assigned each session (`server.py` `generate_round_items()`). Each round gets 1 correct + 2 distractors = 3 items shown. With 3 rounds per game, all items can appear — every item needs an image.
