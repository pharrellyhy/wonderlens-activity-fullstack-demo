Interaction Patterns

交互模式 — 决定孩子与设备的核心互动方式

每个活动属于且仅属于一种交互模式。共 7 种模式,覆盖从拍照探索到角色扮演的多样化体验。

📸 Snap & Discover
拍照探索(7 个活动)
用相机拍摄物品,通过照片展开观察、对比和发现活动。这是 WonderLens 的核心交互模式。
🎵 Listen & Perform
听与做(5 个活动,3 个支持 Tier 0)
听设备的指令后用身体动作或声音来回应——跳跃、模仿动物动作、舞蹈、节奏跟拍。高能量、高趣味性。是唯一包含 Tier 0 (2–3岁) 活动的正式模式。
💬 Voice Dialogue Games
语言对话游戏(5 个活动)
和设备进行口头问答——判断对错、联想接龙、描述挑战、"如果……会怎样" 假设推理。重点培养语言能力。
🎭 Imagination Theater
想象剧场(2 个活动)
角色扮演和创意构建——创造混合生物、扮演记者采访拍摄对象。激发创造力和换位思考。
🗺️ Mission Sequence
任务序列(1 个活动)
按步骤完成多环节的探索任务——收集探险、自然侦探。时间最长、深度最高。
🛠️ Creation Workshop
创造工坊(1 个活动)
引导式创造活动——合作故事构建。孩子在AI引导下创作完作品。
⚡Micro-Activities
微活动(14 个)
15–30 秒的快速活动,穿插在主题互动的回合间隙,调节精力和注意力。不是独立学习活动,而是能量调节工具。

IB PYP Concept Framework

IB PYP 概念框架 — v2.0 新增合规层

每个活动映射到 IB PYP 超学科主题、关键概念和相关概念。活动结束时系统会以 "概念徽章" 的形式为孩子标注所探索的概念。

How We Organize 我们如何组织自己

Sharing the Planet 共享地球

How We Express 我们如何表达自己
Emotion, culture, aesthetics, symbols, creativity
Where We Are in Place & Time 我们身处什么时空

✨ closing_speech 概念标注
🔑 Hook Rule 情感开场规则
intro 段落的第一个 Hook 必须优先孩子的情感体验、分享动机和生活经验。绝对禁止在第一轮进行知识测试。

公式: 情感惊叹 + 对象确认 + 感官特征 (可选) + 个人/情感 Hook 问题

✅ "你有养狗吗?你喜欢毛茸茸的小动物吗?"
❌ "这只狗是什么颜色的?它有几条腿?"
✨ closing_speech 概念标注段落
活动结束时的收场语,自然融入 IB Related Concept 名称作为"概念徽章"。

Age-Tier Progression

年龄分级与递进 — 活动设计的核心

v2.0 新增 Tier 0 (2–3岁) 支持。同一个活动概念在不同分级下有完全不同的学习目标和体验深度。

Tier 0 · 启蒙 Little Explorer
约 2–3 岁
呼唤-回应模式。AI说话、停顿,孩子用1个词或声音回应。AI庆祝任何回应。仅 3 个活动可用:body_mimic, sound_safari, rhythm_echo。语音为主,不依赖屏幕。
Tier 1 · 初阶
约 3–4 岁
简单的感官体验、二元选择(对/错、大/小)、基础词汇。AI做更多引导,孩子以反应为主。
Tier 2 · 进阶
约 5–6 岁
引入比较、分类、多步指令。孩子开始主动描述和提问。AI与孩子轮流主导。
Tier 3 · 高阶
约 7–8 岁
推理、假设验证、系统性思考、创造性表达。孩子主导探索,AI扮演引导者或角色。
Design Principles 设计原则
🚫 Selective Availability 选择性开放
部分复杂活动在低分级下不可用。例如"二十问猜谜"只在 Tier 2/3 开放,因为 3–4 岁儿童尚不具备策略性提问能力。Tier 0 仅 3 个活动可用。
🔄 Same Mechanic, Different Goals 同一机制,不同目标
同一个核心机制服务完全不同的认知目标。例如"对错判断":Tier 1 使用明显荒谬的说法("狗会飞!")锻炼基础判断力;Tier 3 使用常见误解("狗只能看到黑白色"是误解!)培养科学质疑能力。
🌱 Tier 0 — Minimal Demand 启蒙层极简原则
Tier 0 (2–3岁) 采用呼唤-回应模式。AI说话 → 停顿 → 孩子用1个词或声音回应 → AI庆祝任何回应。仅3个活动可用,语音为主不依赖屏幕。目标不是"学习"而是"参与"。
Deep Dive: "True or Silly" 深度解析:对错判断

以下以 True or Silly 为例,完整展示一个正式活动在四个年龄分级下的设计差异。 这是"同一机制、不同认知目标"设计原则的最佳范例。

💬
True or Silly
对错判断 · Voice Dialogue 语言对话游戏
Fun 0.9 Topic: High
AI 围绕拍摄对象生成"对或错"的陈述,孩子判断真伪。同一个简单机制(判断对/错)在分级下服务完全不同的认知目标。
Tier 0 · 启蒙
N/A (Null)
该活动不适用于 Tier 0。2–3岁幼儿尚不具备判断命题真伪的认知能力。
Tier 1 · 初阶
"True or Silly?"
3-4 Rounds Easy
使用明显荒谬的说法("狗会飞!")。屏幕显示搞笑插图。目标是建立"事实 vs 胡说"的基础概念,同时制造笑声。
Tier 2 · 进阶
"Fact Checker!"
5–6 Rounds Medium
使用貌似合理但错误的说法。需要已有知识才能判断。AI 在正确回答后延伸冷知识,引入比较性语言。
Tier 3 · 高阶
"Myth Busters!"
6–8 Rounds Hard
使用常见误解("狗只能看到黑白色")。孩子不仅判断对错,还要推理为什么。AI 引导科学证据思维。

→ 身体类微活动,释放能量

→ 身体/想象类,轻松调剂
🗣️ 大量描述或观察之后
→ 从语言切换到身体表达
🤫 安静活动之后
→ 声音类,提振精力
🐢 节奏缓慢的活动之后
→ 加快节奏提升能量
📖 事实性学习之后
→ 想象类,切换到感性表达
😴 注意力明显下降
→ 即时短爆发,重抓注意力
📱 屏幕互动之后
→ 观察类,目光回到环境
🔊 声音较大的活动之后
→ 回声/耳语,降低音量过渡

▶ Micro-Activity Template (v2.1) 微活动模板 
# ════════════════════════════════════════════════════════════════════
# Micro-Activity Template v2.1 微活动模板
# ════════════════════════════════════════════════════════════════════
# 微活动是穿插在主活动之间的短暂互动 (15–30秒),
# 用于调节节奏、激活身体或切换注意力。
# Micro-activities are brief 15–30s interactions inserted
# between main activities to regulate pace and energy.
# 共 14 个微活动分布在 5 个类别中。

- id: micro_<category>_<name> # 唯一ID — 必须以
  micro_ 开头, e.g. micro_body_stretch

  category: <body | sound | imagine | look | echo>
  # 类别 — from enums.micro_categories:
  # body(身体): physical movement and body awareness
  # sound(声音): making or imitating sounds
  # imagine(想象): creative visualization
  # look(观察): focused observation
  # echo(回声): repeating patterns

  name: "<English Name>" #
    英文名称 — short, action-oriented
  cn: "<中文名称>" # 中文名称 — 2-4

  prompt_template: "<Template with
    {placeholders}>"
  # 提示语模板 — Available placeholders 可用占位符:
  # {object} — photographed object 拍摄物体, e.g. "cat"
  # {sound} — associated sound 关联声音, e.g. "meow"
  # {color} — color name 颜色, e.g. "red"
  # {objects} — environmental items 周围物品 (plural)
  # {fun_phrase} — fun filler phrase 有趣的短语
  # {pause} — rhythmic pause 节奏停顿
  # Example: "Show me how a {object} stretches!"
  # → "Show me how a cat stretches!"

  trigger_context: <trigger_context_id>
  # 触发时机 — from enums.trigger_contexts, e.g.:
  # after_stillness(久坐后) | after_cognitive(高强度认知后)
  # energy_dip(注意力下降) | mid_pathway(路径中段)
  # after_screen(屏幕互动后) | after_listening(聆听后)

  tier_min: <0 | 1 | 2 | 3> # 最低适用年龄段 — 0=T0起可用,
    1=T1起可用, etc.

  cognitive_domains: [<domain_id>, ...] # 认知领域 — 1–2
    domains from enums.cognitive_domains

  physical_movement: <true | false> # 是否涉及肢体运动

  duration_seconds: <15 | 20 | 30> # 持续秒数 — 15, 20, or
      30

  # ── IB 合规 IB Compliance [v2] ────────────────────────
  ib_themes: [<ib_theme_id>, ...] # IB 超学科主题 — from
    enums.ib_themes
  key_concepts: [<concept_name>, ...] # IB 核心概念 — from
    enums.key_concepts
  discipline_concept:
    discipline: <discipline_id>
    concept: <concept_id>
