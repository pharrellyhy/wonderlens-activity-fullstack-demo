# WonderLens Activity Demo — 周报 W22（2026-05-23 ~ 2026-05-29）

## Autodesign 包导入与运行时对齐

- 接入 autodesign demo 包导入能力，让外部活动包可以转成 demo 可播放的活动、资产与支持状态。
- 打通实体绑定、资产就绪、降级准入与启动时可玩性校验，让不可支持或资源缺失的活动在入口处被明确拦截。
- 转换上游运行时回合指令为分阶段步骤说明，让生成活动继承真实引导意图而不是退回默认文案。
- 修复自定义上传文件名的关键词误配，让长词内部片段不再把用户带到错误活动。

## 活动文字游戏端到端搭建

- 新增独立活动目录和启动入口，让活动库可以绕过拍照流程直接进入文字试玩。
- 实现导出活动的 recipe 加载和文本会话推进，让活动选择、开场、回合回答、合成与结束连成完整路径。
- 接入前端活动库、设备框和会话状态，让评审者能在同一页面完成活动选择与回合互动。
- 新增静态展示资产和 manifest 加载，让活动屏幕从提交资产而不是运行时生成图像获得视觉内容。

## 三类代表活动视觉与触控试点

- 实现 Career Decision Role Play 的被动视觉陪伴，让安全选择继续依赖文字输入而不会暴露屏幕选择控件。
- 实现 Guided Drawing 的 Done/Help 设备控制，让构建类活动通过滚动与确认推进而不是依赖触屏。
- 实现 Phoneme Treasure Hunt 的物品滚动选择，让收集类活动可以用同一套无触控设备模型完成选择并回到文字追问。
- 替换三类代表活动的运行时视觉资产，让 pilot 视觉风格收敛到空白背景、平面 Nordic 物件和更稳定的物品集合。
- 打通全活动 live smoke 与浏览器验证，让代表试点落地后仍能保护完整活动库不被破坏。

## 试点流程与界面回归修复

- 修复 Career 决策流程的状态漂移，让确认开场、规则说明和首个安全选择不再互相抢步。
- 修复 Guided Drawing 的开放式提问回退，让孩子在 setup 后进入固定画画步骤而不是被问想画什么。
- 修复 Phoneme Treasure Hunt 的 B 词收集时机和校验，让非 B 词不会被错误保存为已收集物品。
- 优化设备侧边按钮、滚动选择、转录区和镜头文字布局，让活动界面更接近原型且减少裁切、越界与误触。

## 质量修复与代码清理

- 完善来源忠实度、文本模式、设备交互和资产契约回归，让三类代表活动的关键路径有更明确的自动化保护。
- 收敛测试者和开发交接文档，让活动工作流、目标文件和验证结果更容易在后续会话中接续。
- 约束活动资产的事实来源与样式合同，让后续视觉扩展更容易保持可审查和一致。

## 下周关注点
