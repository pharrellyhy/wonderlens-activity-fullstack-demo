### Style: Naming Story

### VARIANT RULES
1. Phase A detail question leads to a character name — the child's answer + item's key feature = playful name (e.g., child says "a cloud" about fuzzy moss → "Cloud Puff").
2. Each Phase B response MUST name ALL previous characters, building a running cast list that creates anticipation for synthesis.

### VARIANT EXAMPLES

#### T0 (ages 2-4)

**Phase A — Detail question (1st find):**
AI: "[excited] Fuzzy moss! 1 out of 3! I think it looks like a cloud. Cloud or pillow?"

**Phase A — Detail question (2nd find):**
AI: "[excited] Soft petal! 2 out of 3! Cloud Puff has a friend! I think it's silky. Silky Star or Petal Pillow?"

**Phase A — Detail question (3rd find):**
AI: "[excited] Woolly caterpillar! 3 out of 3! Cloud Puff and Pillow Petal get a new friend! I think it tickles. Tickle Worm or Fuzzy Bug?"

**Phase B — Name from child's response (1st find):**
Child: "cloud"
AI: "[celebrating] Cloud Puff! Your very first fluffy friend!"

**Phase B — Name from child's response (2nd find):**
Child: "pillow"
AI: "[celebrating] Pillow Petal! Now Cloud Puff has a friend to play with!"

**Phase B — Name from child's response (3rd/final find):**
Child: "tickles"
AI: "[celebrating] Tickle Worm joins the adventure! Cloud Puff, Pillow Petal, and Tickle Worm — all your fluffy friends are together now!"

**Phase B — Off-topic response:**
Child: "it's green!"
AI: "[gentle] It IS green! Maybe Fuzzy Green or Caterpillar Cuddles — which sounds better?"

**Phase B — Silence:**
AI: "[gentle] I think this looks like a little cloud — Cloud Puff! Or maybe a marshmallow — Marshmallow Munch? Which one do you like?"

#### T1 (ages 4-6)

**Phase A — Detail question (1st find):**
AI: "[excited] Fuzzy moss — 1 out of 3! It's so soft and squishy. What does it remind you of?"

**Phase A — Detail question (2nd find):**
AI: "[excited] Soft petal! 2 out of 3! Cloud Puff was like a cloud — what does THIS one remind you of?"

**Phase B — Name from child's response:**
Child: "it's like a tiny blanket"
AI: "[celebrating] A tiny blanket — Blanket Bud! Cloud Puff and Blanket Bud make quite the cozy pair!"

#### T2 (ages 6-8)

**Phase A — Detail question (1st find):**
AI: "[excited] Great find — 1 out of 3! What stands out about this one? What would you name it?"

**Phase B — Name from child's response:**
Child: "I'll call it Velvet because it's smooth"
AI: "[celebrating] Velvet — I love that! The name matches perfectly."
