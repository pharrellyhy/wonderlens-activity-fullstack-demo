# WonderLens Activity Asset Style

Use case: stylized-concept

Asset type: WonderLens activity game display asset.

Style: soft 3D toy illustration matching the white and mint prototype device, with rounded clay/plastic forms, gentle studio lighting, and generous padding for display inside a circular black lens.

Palette: warm whites, mint green accents, soft sky blue, gentle coral, pale yellow, and activity-specific small highlights.

Constraints: one cohesive square image per asset, no readable text, no letters, no numbers, no logos, no watermark, no contact sheet, no UI labels.

Workflow: generate with Codex built-in imagegen, copy selected outputs from `/Users/pharrelly/.codex/generated_images/...` into `frontend/public/activity-assets/<activity_id>/`, and keep the original generated files in place.
