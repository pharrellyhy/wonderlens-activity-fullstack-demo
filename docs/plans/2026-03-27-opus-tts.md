# Plan: Switch TTS Output from PCM/WAV to OGG/Opus via PyAV

## Context

The backend TTS pipeline (Gemini 2.5 Flash TTS) outputs raw PCM 16-bit mono at 24kHz. This is streamed to the frontend, which manually wraps it in WAV headers before playback. Raw PCM is ~384 kbps — unnecessarily large for speech audio. Switching to OGG/Opus (via PyAV) yields ~12x compression at transparent quality, reducing a typical 5-second utterance from ~240 KB to ~20 KB. The frontend also simplifies since browsers natively play OGG/Opus without manual header construction.

## Approach

Batch-encode on the backend: collect all PCM from Gemini, encode to OGG/Opus with PyAV (FFmpeg Python bindings), return complete file. The frontend already collects all audio before playing, so there is no latency regression from batch encoding. Opus encoding of 5s speech takes <5ms.

## Step 2: Add OGG/Opus encoder to `backend/tts.py`

**New imports** at top:
```python
import av
import numpy as np
```

**New constant:**
```python
OPUS_BITRATE_BPS = 32000
```

**New function `_pcm_to_ogg_opus(pcm_data, sample_rate)`:**
- Converts raw PCM bytes to numpy int16 array
- Opens an in-memory OGG container via `av.open(BytesIO(), mode='w', format='ogg')`
- Adds a `libopus` audio stream at the given sample rate, mono, with 32kbps bitrate
- Creates `av.AudioFrame` from the numpy array, encodes, muxes, flushes
- Returns complete OGG/Opus bytes from the BytesIO buffer

**New async function `synthesize_speech_ogg_async(text, tier, max_retries)`:**
- Internally calls existing `synthesize_speech_stream_async()` to collect all PCM chunks
- Joins chunks, ensures even byte count
- Calls `_pcm_to_ogg_opus()` to encode
- On encoding failure, falls back to `_pcm_to_wav()` and logs warning
- Returns `bytes | None`

**Keep existing functions** — `synthesize_speech_stream_async()` is still used internally; `_pcm_to_wav()` is the fallback.

## Step 3: Update `/api/tts` endpoint in `backend/server.py`

**Current** (line 573-579): `StreamingResponse` streaming raw PCM with `audio/pcm` content type.

**New:**
```python
@app.post("/api/tts")
async def text_to_speech(req: TTSRequest) -> Response:
    audio_bytes = await synthesize_speech_ogg_async(req.text, req.tier)
    if audio_bytes is None:
        return Response(status_code=204)
    content_type = "audio/ogg" if audio_bytes[:4] == b"OggS" else "audio/wav"
    return Response(content=audio_bytes, media_type=content_type)
```

- No longer `StreamingResponse` (complete file is small after compression)
- Auto-detects format via `OggS` magic bytes (handles WAV fallback)
- Remove `X-Sample-Rate` header

**Update import** to add `synthesize_speech_ogg_async`.
